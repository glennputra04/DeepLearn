# DeepLearn

A collection of machine learning and deep learning projects completed throughout my university studies. Most of the projects in this repository were developed as part of coursework, assignments, and final projects for various computer science courses.

---

## About

This repository contains implementations of different Deep Learning, Machine Learning, and Natural Language Processing techniques using Python and Jupyter Notebook.

---

## Course Projects

These projects were completed as part of the **Deep Learning** course.

| Project | Description |
|---------|-------------|
| ANN Price Prediction | Predicting prices using an Artificial Neural Network (ANN). |
| CNN Fish Disease Classification | Image classification of fish diseases using Convolutional Neural Networks (CNN). |
| CGAN Fruits | Fruit image generation using Conditional Generative Adversarial Networks (CGAN). |
| Pretrained Transformer Image Captioning | Image caption generation using pretrained Transformer models. |
| RNN Scratch & Pretrained BERT | Comparison between an RNN implemented from scratch and a pretrained BERT model for NLP tasks. |
